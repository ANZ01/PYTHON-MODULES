# 42 Python Modules 🐍

A collection of my solutions for the **Python Modules curriculum at 42 School**.

This curriculum introduces Python progressively, starting with the language fundamentals and moving toward object-oriented programming, exception handling, data structures, file operations, package architecture, design patterns, dependency management, data validation, and functional programming.

---

## 📚 About

The Python Modules are a sequence of projects designed to build a strong understanding of Python through practical exercises.

Instead of focusing on a single area of Python, the curriculum progressively introduces different parts of the language and software development ecosystem.

The exercises are written for **Python 3.10+** and generally require clean code following **flake8**, with type annotations becoming increasingly important throughout the modules.

## 🧠 What the Curriculum Covers

### Python Fundamentals
The first modules establish the basics of Python:

- Variables and expressions
- Functions
- Input and output
- Conditions and loops
- Type hints
- Python program structure

### Object-Oriented Programming
The curriculum then introduces more structured program design:

- Classes and objects
- Attributes and methods
- Inheritance
- Encapsulation
- Abstract classes
- Polymorphism
- Method overriding

### Error Handling

Projects introduce robust error handling using:

- `try`
- `except`
- `raise`
- `finally`
- Built-in exceptions
- Custom exception classes

### Python Collections

The curriculum explores Python's main collection types:

- Lists
- Tuples
- Sets
- Dictionaries
- Comprehensions
- Generators

### File Operations

Later exercises introduce:

- Opening files
- Reading files
- Writing files
- Streams
- Resource cleanup
- Context managers

### Modules & Packages

Python project organization is introduced through:

- Modules
- Packages
- `__init__.py`
- Absolute imports
- Relative imports
- Package interfaces
- Circular dependency management

### Software Design

More advanced modules explore architecture and reusable design using:

- Abstract Base Classes
- Abstract Factory pattern
- Strategy pattern
- Interfaces and capabilities
- Polymorphic systems

### Python Environments

The curriculum also introduces the tools used to manage real Python projects:

- Virtual environments
- `venv`
- `pip`
- Poetry
- Dependency files
- Environment variables
- Package installation

### Data Validation

Using **Pydantic v2**, the exercises cover:

- `BaseModel`
- `Field`
- Type validation
- Constraints
- Custom validation
- Nested models

### Functional Programming

The final modules introduce functional programming concepts:

- Lambda expressions
- Higher-order functions
- Functions as first-class objects
- Closures
- Lexical scope
- `functools`
- Decorators

## ▶️ Running the Exercises

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/42-python-modules.git
cd 42-python-modules
```

Then enter the desired module and exercise:

```bash
cd Python-03/ex0
python3 ft_command_quest.py
```

The exact command depends on the exercise.
